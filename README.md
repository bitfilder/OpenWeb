Консольный инструмент на Python для проведения разведки (Recon), OSINT-анализа и сканирования доменов.

## Возможности

* **Scan:** Проверка HTTP-статус кода, сканирование популярных портов и поиск стандартных директорий.
* **Recon:** Определение IP-адреса, геоданных (страна, город, провайдер), DNS-записей (A, MX, NS, TXT) и заголовков ответов.
* **OSINT:** Парсинг ссылок и Email-адресов с главной страницы сайта, проверка связанных аккаунтов в соцсетях.
* **Отчеты:** Автоматическое сохранение результатов работы в текстовые файлы в папку `reports/`.

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/bitfilder/OpenWeb
cd ИМЯ_РЕПОЗИТОРИЯ
```

2. Создайте и активируйте виртуальное окружение:
```bash
python -m venv venv
# Для Windows:
venv\Scripts\activate
# Для Linux/macOS:
source venv/bin/activate
```

3. Установите зависимости:
```bash
pip install httpx dnspython
```

4. Запустите скрипт:
```bash
python OpenWeb.py
```

## Структура проекта

* `main.py` — точка входа, интерактивное меню.
* `modules/` — функциональные модули (сканирование, OSINT, генерация отчетов).
* `reports/` — каталог с сохраненными отчетами (создается автоматически).
